Merge to Main

Fall term as a GitHub pull request. Each day is a commit; finals are the merge.

Deadline: Augustana fall finals, Fri Dec 11 2026 at 6 PM. One image per day, swapped every morning by a Shortcut.

Put it on your phone

  1. In Shortcuts, tap + to start a new shortcut.
  2. Add Format Date on Current Date, Custom format yyyy-MM-dd.
  3. Add Text: https://zekariasasaminew.github.io/lockscreen-countdowns/merge-to-main/frames/, then the Formatted Date, then .jpg.
  4. Add Get Contents of URL with that Text, then Set Wallpaper: Lock Screen, Show Preview off.
  5. Set your Lock Screen to a Photos wallpaper once, so there is one to replace.
  6. In Automation: Time of Day, 12:01 AM, Daily, Run Immediately, run this shortcut.
  7. Finale: duplicate it with -evening.jpg in place of .jpg, on a 6:01 PM daily automation.

There is a frame for every day from Nov 8 to Dec 11. Untested on every iOS version; action names can vary slightly.

How it was made

Milestones, GitHub-style layout and daily rendering made with Gemini. Designed and directed by Zekarias Asaminew.
